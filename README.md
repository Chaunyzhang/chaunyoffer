## ⬇️ 直接下载（不用会 GitHub）

### 👉 [点击这里下载 chaunyoffer.zip](https://github.com/Chaunyzhang/chaunyoffer/releases/latest/download/chaunyoffer.zip)

**安装只需 4 步：**

1. 📦 下载后**解压** zip，得到 `extension` 文件夹
2. 🌐 打开 Chrome，地址栏输入 `chrome://extensions`，打开右上角「**开发者模式**」
3. 📂 点「**加载已解压的扩展程序**」，选中刚才解压出来的 `extension` 文件夹
4. 🚀 打开任意网申页面，点击页面上的浮窗，粘贴简历 → 点「**自动填充**」

> 💡 之后插件有更新，重新下载 zip 解压覆盖原文件夹，再到 `chrome://extensions` 点一下刷新即可。

## ✨ 它能做什么

- 📄 **简历一站管理**：粘贴文本或导入 Word / PDF，自动解析成结构化档案（教育、实习、工作、项目、技能……），存在你自己的浏览器里
- 🤖 **AI 识别表单**：扫描网页上的表单，靠 AI 辨认「这段是实习经历」「这个是毕业时间」，适配各家公司的不同页面，不写死任何网站
- 🛡️ **保守填写**：拿不准的字段宁可留空标黄，也绝不瞎填——填错比没填更可怕
- 🔊 **完成提示音**：全部填好 / 部分待补 / 填写失败，三种提示音一听就知道结果
- 👀 **全程可见**：浮窗实时显示每个字段填了什么、哪些留给你手动补，填完自动高亮检查项
- 🔒 **隐私优先**：简历只存在浏览器本地；AI 识别走你自己的 API Key，不经过任何第三方服务器

## 🧩 它是怎么工作的

```
粘贴简历 → 本地解析存档 → 扫描网页表单分块 → AI 识别每块的语义
        → 按识别结果逐字段填值 → 没把握的留空标黄 → 提示音 + 日志汇报
```

1. **解析**：简历文本在本地被拆成基本信息 + 各段经历，随时可以手动修正
2. **识别**：填表时把网页表单的 DOM 结构交给 AI（DeepSeek），返回每个输入框该填什么
3. **填写**：程序只负责执行——AI 说填什么就填什么，拿不准就标黄留给你
4. **兜底**：没配 API Key 或 AI 挂了？内置规则引擎整体接管，照样能填个八九不离十

## ⚙️ 首次使用建议

1. 打开浮窗 → **设置页**，填入你的 DeepSeek API Key 并打开 AI 开关（识别准确率的关键）
2. 在**预览页**粘贴简历，检查解析结果，手动补齐缺失字段（性别、出生日期等）
3. 遇到填不准的页面，把浮窗里的日志（带 🧠 标记）截图反馈即可

## 🛠️ 开发者说明

- `extension/` — Chrome 扩展（Manifest V3），原生 JS，无构建步骤，即改即加载
- 简历解析依赖 `extension/vendor/` 下的 mammoth.js（Word）等本地库，零网络请求
- AI 识别为可选增强：配置 DeepSeek API Key 后启用块级语义识别
